# Security policy

Customer Compass V3 is a learning project that uses only synthetic data. It is not deployed anywhere.

- Never commit real API keys, tokens or personal data. `.env` is git-ignored; copy `.env.example` and fill in your own values.
- If you find a leaked secret or a vulnerability, open a private report with GitHub's "Report a vulnerability" button (Security tab), or contact the repository owner. Do not post it in a public issue.
- Any key that has ever been pasted into a doc, log or commit must be rotated.
