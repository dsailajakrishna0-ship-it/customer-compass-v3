---
title: Fleet Visibility rollout package overview
type: product
date: 2026-02-10
---

Fleet Visibility is designed for logistics customers who need real-time
delivery status across multiple carriers, consolidated into one view for
their customer success or operations team.

Base package includes:
- A single dashboard showing delivery status per fleet customer, pulled from
  connected carrier data feeds.
- Configurable delay alerts, set per fleet customer rather than only at the
  account level, so different customers can have different delay thresholds.
- A read-only shareable status link that fleet customers can use to check
  their own delivery status without calling support.

Typical rollout timeline is four to six weeks: two weeks for carrier feed
integration, one to two weeks for configuring per-customer alert thresholds,
and one to two weeks for user acceptance testing before go-live.

Alerting is included in the base package at no additional cost.
